------------------------------------------------------------------------------
 WHERE THE GAME IS
------------------------------------------------------------------------------
 Playable end to end. Gather -> carry -> sell -> upgrade -> unlock better zone,
 with predators arriving on a timer (wolves 6:00, tiger 10:00, bear 15:00) and
 a camp you build to survive them. 674 nodes over six zones, all generated by
 Tools/Survival/Build scene. Save/load is complete (v7). 43 EditMode tests pass.
 Title screen, objective chain (30 goals), win screen, branding and an Android
 APK build all exist.

 NOT shipping on Google Play (user decision, 2026-07-24). Distribution is
 itch.io + sideloaded APK, so no keystore, no AAB, no Play Console, no privacy
 policy, no content rating. BuildTool's debug-signed APK is the deliverable.

------------------------------------------------------------------------------
 3. PRESTIGE — how it works, since it touches five systems
------------------------------------------------------------------------------
 Shipped 2026-07-24. The dead-end was never "no more goals" — it was that COINS
 STOP MEANING ANYTHING once every upgrade is capped. Prestige fixes the sink.

 Prestige.cs        static, +25% sell earnings per valley mastered. Static so it
                    survives the scene reload that performs the reset — which is
                    exactly why DeleteSave has to zero it, or a wiped player
                    keeps a permanent bonus. PrestigeTests pins that.
 Shop.PriceOf       the ONE place the multiplier applies. BasePriceOf holds the
                    authored numbers. Uniform, so the cross-zone price ordering
                    EconomyTests pins cannot break.
 SaveManager        save v8 (valleysMastered). PrestigeReset(keepCamp) writes a
                    fresh save and reloads the scene rather than mutating live
                    components — every system already restores itself from a
                    file, so there is no second reset path to keep in sync.
                    Base capacity/speed/health are captured in Awake, BEFORE
                    Load() overwrites them; there is nowhere else to read "what
                    a fresh player starts with" from once a run is loaded.
 VictoryPanel       three buttons: keep camp / raze camp / keep playing.
 BuildCatalogSetup  builds that panel (700x~600, was 640x420).

 Carried across a reset: prestige count (+1), lifetime stats, and the placed
 structures if you chose KEEP CAMP. Everything else returns to first-run values.
